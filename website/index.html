app.ts 
import { Application } from '@framesquared/app';
import { TreeGrid } from '@framesquared/ui';
import { TreeStore } from '@framesquared/data';

const app = new Application({
  name: 'MyApp',
  launch: () => {
    new TreeGrid({
      renderTo: document.body,
      store: new TreeStore({ autoLoad: true }),
      columns: [
        { text: 'Name', dataIndex: 'name', flex: 1 },
        { text: 'Status', dataIndex: 'status' }
      ]
    });
  }
});

Why Framesquared

Enterprise power.
Modern foundations.

Everything you loved about ExtJS, rebuilt for how the web works today.

⚡

TypeScript Native

Written entirely in TypeScript 5.5+ with strict mode. Full autocomplete, type safety, and refactoring support out of the box — no type declaration files bolted on after the fact.

📦

Native ESM

No AMD, no CommonJS shims. Pure ES modules throughout, enabling tree-shaking, lazy imports, and compatibility with every modern bundler and runtime.

🧩

Clean Room

Built from scratch without referencing or depending on the original ExtJS source. A truly independent implementation with a modern architecture informed by years of real-world usage.

🎨

Theme System

CSS-in-JS token architecture with Classic, Modern, and Dark themes included. Create custom themes with a first-class API that controls every visual detail.

♿

Accessibility First

AriaManager, FocusManager, and full keyboard navigation built into every component. WCAG 2.1 AA compliance is a design goal, not an afterthought.

🌐

Internationalization

RTL support and locale bundles for English, Spanish, and Arabic included. The i18n system is extensible to any language without framework changes.

Architecture

Modular by design

A carefully layered monorepo. Import only what you need.

@framesquared/core

The foundation everything else is built on. Class system, event bus, observable pattern, ARIA utilities, focus management, gesture recognition, keyboard mapping, and i18n locale bundles.

Class SystemEvent BusObservable ARIA ManagerFocus ManagerGestures Keyboard Mapi18n / l10nSanitization

@framesquared/data

A full data layer with models, stores, and multiple proxy backends. Supports relational data through HasOne, HasMany, BelongsTo, and ManyToMany associations. Includes change tracking, session management, and real-time via WebSocket.

ModelsStoresTreeStore Ajax ProxyREST ProxyWebSocket GraphQLAssociationsSession

@framesquared/component

Base component lifecycle, rendering pipeline, and container management. Implements ComponentQuery — a CSS-like selector system for querying the component tree.

LifecycleContainerComponentQuery Template SystemRendering Pipeline

@framesquared/layout

Nine layout managers covering every use case from simple boxes to complex border layouts. Includes a ResponsivePlugin for adaptive UIs that react to container size changes.

BorderLayoutBoxLayoutCardLayout FitLayoutAnchorLayoutTableLayout ColumnLayoutAccordionLayoutResponsive

@framesquared/ui

The full widget library: panels, windows, dialogs, toolbars, menus, tabs, trees, and the flagship TreeGrid component with 22 live examples.

Panel / WindowMessageBoxToolbar MenuTabPanelTreeGrid DataViewListViewTooltip

@framesquared/grid

A high-performance data grid with virtual scrolling, locked columns, grouping, summaries, cell/row editing, clipboard support, and spreadsheet-style selection.

Virtual ScrollLocked ColumnsGrouping SummaryCell EditingRow Editing ClipboardDragDropSpreadsheet Select

@framesquared/form

Every form field you'll ever need: text, number, date, color, combo box, tag field, sliders, file upload, and a full rich-text HTML editor with validation built in.

TextFieldNumberFieldDatePicker ColorPickerComboBoxTagField SliderFileFieldHtmlEditor

@framesquared/app

Full MVC/MVVM application architecture with ViewController, ViewModel, two-way data binding, hash/history routing, and state management.

ApplicationViewControllerViewModel BindingRouterState
Flagship Component

TreeGrid

The most powerful hierarchical data grid available for the web. Renders 100,000+ nodes at a silky 60fps with virtual scrolling, and supports a full feature set that puts most grids to shame.

  • ✓ Inline cell & row editing with rich field types
  • ✓ Drag-and-drop node reordering
  • ✓ Tri-state checkbox selection
  • ✓ Async lazy-loading from REST APIs
  • ✓ Locked / frozen columns
  • ✓ Export to CSV, JSON, TSV
  • ✓ State persistence via localStorage
  • ✓ Full keyboard navigation & ARIA
