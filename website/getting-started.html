Prerequisites

Before installing Framesquared, make sure you have the following installed:

  • Node.js ≥ 18.0.0
  • pnpm ≥ 8.0.0 (strongly recommended; npm and yarn also work)
  • A modern browser (Chrome 90+, Firefox 88+, Safari 14+)
bash 
# Check your Node.js version
node --version   # should be ≥ 18.0.0

# Install pnpm globally if needed
npm install -g pnpm@latest

Installation

Framesquared is organized as a monorepo. Install only the packages you need. The most common starting point is @framesquared/ui combined with @framesquared/data.

bash 
# Install the UI widget library and data layer
pnpm add @framesquared/ui @framesquared/data

# Optional: add the application architecture package
pnpm add @framesquared/app

# Optional: add form components
pnpm add @framesquared/form

# Optional: add the standalone grid package
pnpm add @framesquared/grid

All packages are pure ESM. Your bundler (Vite, Rollup, esbuild, Webpack 5+) will handle tree-shaking automatically — unused components are not included in your production bundle.

Project Structure

A typical Framesquared project looks like this:

text 
my-app/
├── src/
│   ├── app.ts          # Application entry point
│   ├── models/         # Data model definitions
│   ├── stores/         # Store definitions
│   ├── views/          # Component/view definitions
│   └── controllers/    # ViewControllers
├── index.html
├── tsconfig.json
└── package.json
json 
{
  "compilerOptions": {

    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "lib": ["ESNext", "DOM"]
  }
}

Your First App

The simplest possible Framesquared app creates an Application instance and renders a panel into the document body.

typescript 
import { Application } from '@framesquared/app';
import { Panel } from '@framesquared/ui';

new Application({
  name: 'HelloWorld',
  launch() {
    new Panel({
      renderTo: document.body,
      title: 'Hello, Framesquared!',
      html: '<p>Welcome to your first app.</p>',
      width: 400,
      height: 200
    });
  }
});

Adding Data

Connect a Store backed by a REST API proxy and display the results in a component.

Define a Model

typescript 
import { Model, Field } from '@framesquared/data';

class User extends Model {
  static fields: Field[] = [
    { name: 'id',    type: 'int' },
    { name: 'name',  type: 'string' },
    { name: 'email', type: 'string' },
    { name: 'role',  type: 'string', defaultValue: 'viewer' }
  ];
}

Create a Store

typescript 
import { Store } from '@framesquared/data';

const userStore = new Store({
  model: User,
  proxy: {
    type: 'rest',
    url: '/api/users',
    reader: { type: 'json', rootProperty: 'data' }
  },
  autoLoad: true
});

TreeGrid Quickstart

The TreeGrid is the flagship component. Here's a complete example with async loading, multi-column layout, and inline cell editing.

typescript 
import { TreeGrid } from '@framesquared/ui';
import { TreeStore } from '@framesquared/data';

const store = new TreeStore({
  proxy: {
    type: 'ajax',
    url: '/api/tree-nodes',
    reader: { type: 'json', rootProperty: 'nodes' }
  },
  autoLoad: true
});

const grid = new TreeGrid({
  renderTo: document.getElementById('app')!,
  store,
  height: 600,

  columns: [
    {
      xtype: 'treecolumn',
      text: 'Name',
      dataIndex: 'name',
      flex: 2,
      editor: { xtype: 'textfield' }
    },
    {
      text: 'Status',
      dataIndex: 'status',
      width: 120,
      editor: {
        xtype: 'combobox',
        store: ['Active', 'Pending', 'Done']
      }
    },
    {
      text: 'Due Date',
      dataIndex: 'dueDate',
      xtype: 'datecolumn',
      format: 'Y-m-d',
      width: 110
    }
  ],

  plugins: {
    cellediting: { clicksToEdit: 2 }
  },

  selModel: { mode: 'MULTI' },
  rootVisible: false
});

Class System

Every Framesquared object extends Base from @framesquared/core. The class system provides a consistent constructor config pattern, mixins, and the xtype component alias registry.

typescript 
import { Base, register } from '@framesquared/core';
import { Panel } from '@framesquared/ui';

// Extend any component
@register('myapp-userpanel')
class UserPanel extends Panel {
  declare config: Panel['config'] & {
    userId?: number;
  };

  constructor(config?: UserPanel['config']) {
    super(config);
    // config properties are merged and applied automatically
  }

  onRender() {
    super.onRender();
    this.loadUser(this.userId);
  }

  loadUser(id?: number) {
    // ...
  }
}

// Use via xtype anywhere in the component tree
const panel = new UserPanel({ userId: 42, title: 'Profile' });

Events

All components inherit from Observable, giving them a fully-featured event API.

typescript 
// Listen to events
grid.on('selectionchange', (grid, selected) => {
  console.log('Selected:', selected.length, 'rows');
});

// One-time listener
store.once('load', () => {
  console.log('Store loaded for the first time');
});

// Fire custom events
myComponent.fireEvent('myevent', myComponent, { data: 42 });

// Remove a listener
const handler = () => { /* ... */ };
grid.on('itemclick', handler);
grid.un('itemclick', handler);

Stores & Models

Stores are the single source of truth for component data. They hold a collection of Model instances and connect to remote or local data through Proxies.

typescript 
// Filter store data
store.filter('status', 'Active');
store.filter([
  { property: 'role', value: 'admin' },
  { property: 'active', value: true }
]);

// Sort
store.sort('lastName', 'ASC');

// Group
store.group('department');

// CRUD
const record = store.add({ name: 'Alice', role: 'admin' });
record.set('name', 'Alice Smith');
store.sync();  // Commits to the proxy

// Listen to changes
store.on('datachanged', () => console.log('Data updated'));

Theming

Switch between the built-in themes at runtime, or create a fully custom theme using the CSS token API.

typescript 
import { ThemeManager, DarkTheme, ModernTheme } from '@framesquared/theme';

// Apply a theme
ThemeManager.setTheme(new DarkTheme());

// Switch at runtime (no page reload)
document.getElementById('toggle')!.addEventListener('click', () => {
  ThemeManager.setTheme(new ModernTheme());
});

// Create a custom theme
import { Theme } from '@framesquared/theme';

class BrandTheme extends Theme {
  tokens = {
    ...ModernTheme.tokens,
    primaryColor: '#00b894',
    fontFamily: '"Söhne", sans-serif',
    borderRadius: '6px'
  };
}

ThemeManager.setTheme(new BrandTheme());

MVC / MVVM

For larger applications, the @framesquared/app package provides full MVC and MVVM architecture with automatic binding.

typescript 
import { ViewController, ViewModel } from '@framesquared/app';
import { Panel, Button } from '@framesquared/ui';

class UserController extends ViewController {
  onSaveClick() {
    const vm = this.getViewModel();
    const user = vm.get('selectedUser');
    user.save();
  }
}

const view = new Panel({
  controller: new UserController(),
  viewModel: new ViewModel({
    data: { selectedUser: null, title: 'User Manager' }
  }),
  bind: {
    title: '{title}'
  },
  items: [
    new Button({
      text: 'Save',
      handler: 'onSaveClick'   // resolved on the controller
    })
  ]
});

Routing

The built-in Router supports both hash and History API routing with named parameters.

typescript 
import { Router } from '@framesquared/app';

const router = new Router({
  routes: {
    'home':           'onHome',
    'users':          'onUsers',
    'users/:id':      'onUserDetail',
    'reports/:year/:month': 'onReport'
  }
});

router.on('beforeroute', (route) => {
  // Guard — return false to cancel navigation
  if (!isAuthenticated()) return false;
});

function onUserDetail(id: string) {
  console.log('Load user', id);
}

router.start();

Accessibility

Framesquared ships accessibility as a first-class feature. All interactive components manage ARIA roles, states, and properties automatically.

  • Full keyboard navigation in Grid, TreeGrid, Menu, TabPanel, and Dialog
  • ARIA live regions for dynamic content updates
  • Focus trapping in modal Dialogs and Windows
  • RTL text direction support in all layout managers
  • High-contrast mode support via CSS custom properties
typescript 
import { AriaManager, FocusManager } from '@framesquared/core';

// Announce a message to screen reader users
AriaManager.announce('Record saved successfully', 'polite');

// Trap focus within a container (e.g. a dialog)
FocusManager.trap(dialogElement);

// Release focus trap
FocusManager.release();
