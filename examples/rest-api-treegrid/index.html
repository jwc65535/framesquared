REST API Explorer

Full CRUD against api.restful-api.dev/collections using your private x-api-key. Use the Actions column in each row to Edit (PUT), Rename (PATCH), or Delete. Click Add to create.

GET /collections GET /collections/{col}/objects GET /collections/{col}/objects/{id} POST /…/objects PUT /…/{id} PATCH /…/{id} DELETE /…/{id}
Getting started — API key required
  1. 1 Visit restful-api.dev and click Get API key to register a free account.
  2. 2 Copy your key from the dashboard — it looks like xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.
  3. 3 Paste it into the API Key field below, then press Enter or click Refresh.
  4. 4 Type a Collection name (e.g. devices) and click Seed sample data to populate it, or Add — POST to create your own objects.
